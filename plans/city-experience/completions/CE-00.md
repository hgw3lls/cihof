## Existing failures versus introduced regressions

CE-00 introduced no failure. Two failures in the tree are introduced by the
in-progress CE-02 work:

1. `tests/index-experience.spec.ts:159` — `LinksScene` receives the globally
   filtered people list while its search box writes the shared global query, so
   searching a name in Links empties that person's constellation and no
   shared-induction-year nodes exist. Reproduced 2/2.
2. `tests/years-media.spec.ts:163` — the single-valued `detail` union discards an
   active film when a record opens over it, so closing the record cannot restore
   focus to `#filmRecordButton`. This breaks tested MG-03 behavior. See D08.

Separately, `npm run test:kiosk` collects zero tests. The proximate cause is
`tests/exhibit-state.spec.ts` (CE-02); the latent cause is CE-01's `buildInfo`
import into `interpretiveModel.ts`. CE-01's recorded 72/72 was accurate when
written.

`tests/links-relationships.spec.ts:221` is an order-dependent flake in existing
`LinksScene` focus handling: it failed once in a partial run and passed 3/3 in
isolation and in the 72-test run. It is not a CE regression.

The pinned Node 22 runtime remains unable to start
(`libsimdutf.34.dylib` missing). A concurrent Homebrew `simdutf` 9.2.0 rebuild
in an interactive shell also made Node 26 temporarily unavailable during this
stage.
