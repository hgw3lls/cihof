# Installation sign-off

The automated tests check the software in a browser. They cannot tell whether
a visitor in a wheelchair can reach the screen, whether a screen reader user
can find their way, or whether the museum stands behind what is shown. People
check those things, and this sheet records who checked them and when.

Print it, and fill it in by hand at the display. Each section has a named
person responsible. A section is signed off only when every line in it is
ticked, or has a note saying why not and who accepted that. **Do not tick
anything you did not check yourself.** A blank is honest. A tick nobody earned
is not.

When it is complete, scan it and keep it with the release it describes (staff
guide section 8).
