# Editorial work that unlocks the interactions

Code can create the affordances; it cannot authorize the historical claims, identity labels, images or relationships they present. This work uses the existing staff portal and canonical sources, not a visitor-facing editor.

## Prototype content packet

Choose about 12 people for the first richly connected prototype while retaining access to every current base profile. This is a coverage exercise, not an importance ranking or permanent featured hierarchy.

For each prototype person, aim to review a specific one-sentence contribution; one or more precisely described community/heritage assertions where supported; one documented Cleveland/Greater Cleveland place association; a short story with independently sourced steps; and one usable image with caption, credit and target permission. Sparse records should remain sparse rather than be padded.

For the shared city, aim to review 4–6 places and at least 6 explained connections or comparisons. These quantities are suggested prototype targets, not facts about the present collection or quotas for any ethnicity. Connections can involve places, organizations or events; direct person-to-person relationships are not mandatory where unsupported.

## Queues to create or extend in the portal

**Vocabulary:** original label, current field, proposed typed meaning, source wording, source citation, decision and aliases. Resolve mixtures such as institutions inside Community without losing the original evidence.

**Places:** seed, name variants, neighborhood/address, schematic versus geographic location, role of each person, evidence, temporal scope, permissions for any image or map geometry. Approve the association and the location separately.

**Stories:** headline/body, source text versus interpretation, evidence locator, related entity/event IDs, date precision, review status, public/kiosk target. Review each claim; a record-level “curated” label is insufficient for a changed story.

**Connections:** endpoints, direct/shared/comparison/induction semantics, forward/reverse text, citations, review decision and target. No automatic approvals based on shared surnames or inferred organization mentions.

**Media and archive:** existing asset, actual rights scope, captions/alt/credit, associated claim, local derivative, public versus kiosk permission. The 11 current archive leads are research leads; catalogue discovery is not item inspection or reproduction permission.

## Review state is not publication state

Use Draft → Needs review → Approved or Withheld, with an actual decision reference. Keep source certainty, factual review and display rights separate. A withdrawn claim removes its visible story/connection without removing the person from the base collection.

The existing 111 `approvalStatus: draft` values need semantic reconciliation by the project's authorized reviewers. Do not ask Codex to flip them as a shortcut. Preserve the already accepted base experience while additions are reviewed.

## Release coverage report

Generate counts by content capability: people with an approved short contribution, reviewed community assertions, reviewed place associations, dated activity, source-linked stories, image captions, and playable cleared media. Report coverage as coverage, not community importance or a measure of historical contribution.

Check whether poorly documented records, long names, multiple identities, and missing media remain findable. No group should disappear merely because it has fewer photographs or unresolved location metadata.

## Editorial sign-off record

Use [the blank content decision template](templates/content-decision.json) for structure, adapted to the portal's actual schema. It is deliberately unfilled. A developer or agent may draft a proposed claim for review with evidence, but must not put an approving reviewer name, date or permission into the record without an authorized decision.

English interface copy can be the initial release. Add additional languages only when chosen and reviewed with relevant communities; do not assume ethnicity predicts language or that unreviewed machine translation is suitable for quotations and identity labels.
