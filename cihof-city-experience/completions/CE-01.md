## Changes and rationale

- Added typed evidence, review, publication-target, vocabulary, affiliation,
  geometry, date-precision, event, and relationship-presentation contracts.
- Added a canonical `person:<inductee-id>` adapter without name matching.
- Preserved all 111 base profiles through an explicit id/name compatibility
  rule despite all current `approvalStatus` values being `draft`.
- Centralized pure enrichment publication selectors used by the visitor UI and
  Vite serializer. Explicit new content requires approved review metadata,
  decision reference, content version, evidence where applicable, and an
  independently permitted target.
- Extended public/kiosk serialization to filter story sections, places,
  archive workflow records, explicit relationships, candidate entities,
  provisional graph rows, and target-ineligible media in split files and the
  runtime bundle. Referential integrity is checked after filtering.
- Canonicalized the 14 place seeds under `data/cihof_places.json`. They remain
  schematic, staff-only review inputs; no coordinates or associations were
  inferred or approved.
- Generated a staff-only review export for 53 unresolved legacy vocabulary
  labels, 14 place seeds, 3 story starters, and 11 archive leads. Public/kiosk
  builds exclude this export; the portal artifact retains it.
- Added deterministic fixtures for multiple affiliations, uncertain/unknown
  dates, public/kiosk differences, withheld claims, stable IDs, and legacy base
  compatibility. Fixture IDs are absent from built visitor artifacts.
